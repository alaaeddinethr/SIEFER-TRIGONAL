# SIEFER TRIGONAL® Maroc: Showcase Website

Website for **SIEFER TRIGONAL® Maroc**, which distributes SIEFER industrial grinding, dispersing and mixing machines (TRIGONAL® technology) in Morocco.

**Live site:** https://siefer-trigonal-maroc.com (served by GitHub Pages through the custom domain in `CNAME`)

## Purpose

Present the machine range and its applications to Moroccan industrial buyers (food, chemicals, cosmetics, pharmaceuticals) and generate qualified enquiries for the sales team.

## Technical choices

- Single bundled `index.html` with its assets embedded, so the site is one file to host and back up
- Static hosting on GitHub Pages with a custom domain: no server to maintain and HTTPS included
- Companion tool: the prospecting CRM in [CRM](https://github.com/alaaeddinethr/CRM)
